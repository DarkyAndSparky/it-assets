# Changelog

Формат по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Подробный бэклог и статусы задач — во внешнем файле `ROADMAP-CONSOLIDATED.md`

что реально попало в `dev`.

## [Unreleased]

### Added
- Единый источник правды по версии перенесён из `package.json` в отдельный
  файл `VERSION` в корне (plain text, формат `<alpha|beta>-N-YYwWW-NN`) —
  идея подсмотрена в соседнем проекте atlas-server. `package.json`,
  README-бейдж и `docs/index.html` теперь синхронизируются ОТ него через
  `scripts/sync-version.js` (переписан под новый источник), а не наоборот.
  `START.bat`/`start.sh` тоже читают версию напрямую из `VERSION`.
- Консольный баннер при старте сервера обрамлён рамкой (`─`×60) по образцу
  atlas-server/printBanner — вся прежняя диагностика (проверка прав на
  запись, размер БД, самопроверка записи SQLite) сохранена без изменений,
  только визуально оформлена.
- Docker: `HEALTHCHECK` в `Dockerfile` и явный `healthcheck:` в
  `docker-compose.yml` на существующем `GET /api/health` (идея из
  atlas-server) + копирование `VERSION`/`CHANGELOG.md` в образ (нужны
  карточке «О системе»).
- Автобэкап теперь настраивается через `IT_ASSETS_AUTO_BACKUP_ENABLED` и
  `IT_ASSETS_AUTO_BACKUP_INTERVAL_MIN` (идея настраиваемости через env —
  из atlas-server/backupScheduler.js; сама система бэкапов у нас осталась
  своя — ZIP с БД+конфигом, раздельные лимиты по типам). По умолчанию
  поведение не меняется (включено, раз в час).
- Добавлен `.env.example` — раньше все переменные окружения были
  задокументированы только в разрозненных комментариях по коду.
- Добавлен `THIRD_PARTY_LICENSES.md` (идея из atlas-server) — сводка по
  лицензиям npm-зависимостей, сгенерирована по фактически установленному
  дереву `node_modules` (343 транзитивных пакета, все пермиссивные лицензии,
  кроме одного пакета без указанной лицензии в манифесте — не используется
  напрямую нашим кодом).
- `docs/index.html` актуализирован под всё сделанное в Track 0/8: новые
  переменные окружения (×3 таблицы в файле), консольный баннер (обновлён
  пример вывода), структура файлов (VERSION/CHANGELOG.md/THIRD_PARTY_LICENSES.md/
  .env.example/Dockerfile/scripts/), новые эндпоинты `/api/settings/system-info`,
  `/api/settings/version`, `/api/settings/health`, `/api/health` (раньше в
  документации не было вообще), раздел авторизации дополнен объяснением
  `requireLogin` vs `requireAuth`. Заодно исправлено фактически неверное
  утверждение «PORT больше не используется / .env не используется» — оба
  давно используются.
- REF-1: бэкапы и QR-генератор вынесены из `server/index.js` в
  `server/routes/backup.routes.js`/`qr.routes.js` (тот же паттерн, что и
  остальные домены) — `server/index.js` сократился с 727 до 329 строк.
  Логика перенесена 1:1, без изменений поведения.

### Checked
- REF-2: обновление `uuid` 11 → 14 (было в изначальном плане) — **проверено
  и отклонено осознанно**. Начиная с `uuid@12` пакет убрал поддержку
  CommonJS (официальная позиция мейнтейнеров: «For CommonJS codebases, use
  uuid@11»); апгрейд сломает сервер на старте (`ERR_REQUIRE_ESM`, весь наш
  код на `require()`). Замена на `node:crypto.randomUUID()` тоже не
  подходит — генерирует только v4, нам нужен v7 (time-ordered). Остаёмся на
  `11.1.1` — это верное решение, не технический долг.
- REF-3: Docker — статус был неясен, сверено с реальным состоянием
  репозитория. Закрыто через Track 8/INFRA-11 (см. выше).

### Fixed
- Docker-сборка была сломана после INFRA-3: `npm ci` запускался ДО
  копирования `scripts/` в образ, а lifecycle-скрипт `prepare` (git-хук)
  требует `scripts/install-hooks.js` — билд падал бы с "Cannot find
  module". Исправлено флагом `--ignore-scripts` (хуки внутри Docker-образа
  всё равно не нужны — там нет `.git`).
- `.dockerignore` содержал `*.md`, что исключало `CHANGELOG.md` из билд-
  контекста ещё до попытки его скопировать — добавлено точечное
  исключение `!CHANGELOG.md`.

- INFRA-3: git pre-commit хук (`scripts/hooks/pre-commit` +

- INFRA-4: `scripts/sync-version.js` — синхронизация версии из `package.json`
  в README-бейдж и `docs/index.html` (обнаружил и исправил реальный дрейф:
  docs была на `26w27-02`, актуальная — `26w29-01`).
- INFRA-5: `GET /api/settings/system-info` (admin-only) и
  `GET /api/settings/version` — версия, окружение Node, реально
  установленные зависимости, размер БД, счётчики сущностей, инфо по
