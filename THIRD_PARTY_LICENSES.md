# Лицензии сторонних компонентов

Этот файл — сводка по лицензиям npm-зависимостей проекта. Не заменяет
юридическую консультацию — если проект когда-нибудь пойдёт в публичный
релиз/дистрибуцию за пределами внутреннего использования, стоит
перепроверить список заново (зависимости обновляются) инструментом вроде
`license-checker`.

Список ниже сгенерирован по фактически установленному дереву
`node_modules` (production-зависимости, `npm ci --omit=dev`) на дату
последнего обновления этого файла.

(SQLite — через встроенный `node:sqlite`, часть самого Node.js, отдельной
npm-зависимостью не является.)

Все перечисленные лицензии — пермиссивные, совместимы друг с другом и с
внутренним использованием без ограничений.

### Пакет без указанной лицензии в манифесте

- **exif-parser** (транзитивная зависимость через `@jimp/core`, глубоко в
  дереве — не используется нашим кодом напрямую) — поле `license`/`licenses`
  отсутствует в его `package.json`. На GitHub-странице пакета лицензия не
  заявлена явно. Не критично для внутреннего использования, но при
  публичном релизе стоит либо найти лицензию у автора, либо исключить
  ветку зависимостей, которая его тянет.

## Как перепроверить

```bash
npx license-checker --production --summary
```
